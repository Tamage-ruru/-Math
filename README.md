# お金の学校 / Money School

お金の稼ぎ方を基礎から体系的に学べる、無料の学習用Webサイトです。

## 内容

- **お金の考え方（マインドセット）** — 稼ぐ前に知っておきたい土台の考え方
- **収入をつくる3つの柱** — 労働収入・副業/事業収入・資産収入
- **稼ぎ方カタログ 12選** — 難易度・初期費用・収入目安つき（カテゴリで絞り込み可）
- **ゼロから始める5ステップ** — 実践ロードマップ
- **投資・資産運用の基礎** — 複利シミュレーター付き
- **詐欺・怪しい儲け話の見分け方** — 身を守るための知識
- **よくある質問（Q&A）**

## 使い方

`index.html` をブラウザで開くだけで動作します。外部ライブラリ不要の単一HTMLファイルです。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | お金の学校（メインサイト） |
| `math.html` | 数学マスター（別コンテンツ） |
